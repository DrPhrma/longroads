# Long Roads

Endless 3D driving in the browser.

**Play:** [drphrma.github.io/longroads](https://drphrma.github.io/longroads/)

## Controls

| Input | Action |
|--------|--------|
| W / ↑ | Accelerate |
| S / ↓ / Space | Brake |
| A D / ← → | Steer |
| R | Restart |
| Touch | Left = left, center = gas, right = right |

## Stack

- Three.js (CDN)
- Vanilla JS modules
- GitHub Pages

## Dev

Open `index.html` via a local server (modules need HTTP):

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
